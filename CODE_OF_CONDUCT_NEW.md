# Code of Conduct

## Our Pledge
We pledge to make participation in our project harassment-free.

## Our Standards
Be respectful and inclusive.

## Enforcement Responsibilities
Project maintainers are responsible for enforcing standards.

## Scope
This Code of Conduct applies to all project spaces.

## Enforcement
Instances of abusive behavior may be reported.

## Enforcement Guidelines
Maintainers will take appropriate action.

## Attribution
This Code of Conduct is adapted from the Contributor Covenant.
